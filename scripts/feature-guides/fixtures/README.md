`extension-guide-blocks.json` is a pinned copy of `ui/src/test/fixtures/extension-guide-blocks.json` from yourcove/cove, at commit 08484f933502c509c49f94057bfb1d9148b3f220. It lists the blocks Cove's User Guide renders and those it drops. `check-feature-guides.test.mjs` and the documentation site's renderer check both test against it. To update it, copy the file from a newer Cove commit, change the commit above, and run `npm test` in `docs-site/`.

`reserved-topic-ids.json` lists the User Guide topic ids Cove keeps for its own topics, at the Cove commit named inside it: the ids of its `docs/feature-guides/*.json` guides, and the keys of `legacyTopicAliases` in `ui/src/components/TutorialStoryboardDialog.tsx`. Cove hides an extension guide that uses one, so the check reports it. Regenerate it when Cove adds or renames topics.
