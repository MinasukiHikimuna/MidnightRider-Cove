# Data Quality

Data Quality adds a dedicated Cove page for saved video, audio, performer occurrence, and tag reviews. Enable it in **Settings → My → Interface → Navigation**.

Video and occurrence reviews put the player, active item, current tags, and configured actions beside an independently scrollable queue. Occurrence actions affect only the active performer in that video. Matching partners are reviewed together; switching partners preserves playback and clip boundaries. Video actions affect the video itself. Existing multi-tag actions, explicit absence tags, and legacy occurrence tag-choice reviews remain supported.

Audio reviews and audio performer-occurrence reviews work the same way, on Cove’s audio player. Audios have no card grid, so both run one audio at a time: there is no **Multiple** layout, no card annotations or tag bins, and no **Select all on page load**. Because an audio shows nothing while it plays, its **description** sits directly under the player in both audio review kinds, with a **Description** control that collapses it; that collapsed choice is remembered per browser and is not part of the saved review. Audio occurrence actions, assessments, **Apply to all matching occurrences** and undo behave exactly as the video ones do, writing to the audio and to its performer occurrences. Audio reviews need **audios.write**; occurrence tagging needs **tags.write**. The first occurrence assessment on an audio offers to add audios to the existing `confirmed_absent_occurrence_tags` custom field, extending it rather than replacing the video values.

Normal video reviews also support **Review layout → Multiple videos**, with Grid/Wall cards, multi-selection, action shortcuts, and quick previews. The checkmark on each card is the selection state and stays visible in every view; the accent ring only marks the focused card. **Select all on page** in the actions sidebar (shortcut **A**) selects every card on the current page and turns into **Clear selection** once all are selected. Action letters, **A** and **Esc** work from the page body, the cards, the pagination rows and the sidebar buttons, while the host toolbar and dialogs keep their own keys; a shortcut that cannot run says why. **Edit review → Appearance → Preferred review layout** saves the default for that rule, and **Select all videos on page load** (also offered for tag reviews) starts every page with all cards selected so a quick review can confirm the whole page at once. Applying an action to the whole page brings the next page in selected too, while a hand-trimmed selection stays trimmed after the refresh. Reviews that start from the end keep moving towards the first page: once a page's own cards are answered, the queue continues head-ward even when items from the pages already reviewed have shifted into it, so a deliberately skipped tail accumulates behind the cursor instead of pulling it back. Existing rules keep single-video review until a different preference is saved; occurrence reviews retain their performer-specific workspace.

Under **Appearance → Card annotations**, enable **tags** and choose parent tags in **Card tag bins**. Each video card displays only its assigned descendant tags under those parents, excluding the parents themselves. This explicit setting is independent of the queue filters. **Queue tag bins** separately provides tag buttons that narrow the current queue.

The URL owns the complete effective query: search, scene filters, performer scope and occurrence conditions, sorting, page size, page, and traversal direction. Bare review links load saved defaults and serialize them. Query-bearing links remain independent of subsequent default changes, including explicit empty filters. Changing any queue criteria reveals the same compact **Save changes to review filters** and **Reset to default review filters** controls in video, performer-occurrence, and tag reviews. **Edit review** remains the path for changing the complete rule. Opening another review starts with its defaults. New reviews start from the end; existing direction settings and explicit URL pages are honored.

Actions apply and advance by default. When the current video is playing, applying a change and advancing to another video starts playback there too; a paused video stays paused. Shift-click or Shift plus the numbered shortcut applies and stays; each writing action also has **Apply & stay**. **Edit tags** uses Cove's shared tag selector for arbitrary additions and removals. **Save** stays, **Save & next** advances, and **Cancel** discards the local draft. Shortcuts are suspended while typing, editing tags, or using dialogs and player controls.

In single-video and occurrence reviews, **Skip** only moves the cursor. Eligibility comes from current filters, without reviewed/inconclusive states or persistent position. Successful tag saves refresh queue membership and counts. Occurrences that no longer match the filters leave the queue; a scene leaves after its last matching performer is tagged. Skipped and still-matching items are available again when their page is revisited. These workspaces leave legacy progress untouched; multiple-video reviews retain the card selection, view preference, and progress workflow.

**Occurrence assessments** let an occurrence action mark a tag present, mark it absent, or clear the absence for the active performer. Absences are stored on the video in the `confirmed_absent_occurrence_tags` custom field as `<performerId>:<tagId>` text values, created by the setup prompt on reviews that use an assessment step. A "Has none of the selected tags" queue hides occurrences confirmed absent for every condition tag unless **Hide occurrences confirmed absent** is switched off; with one target performer and one condition tag Cove filters them out itself, otherwise they are hidden in the browser. Name the same tags in the assessment step as in the condition: absences match exact tag ids. Batches do not offer assessment actions.

**Apply to all matching occurrences** runs a configured occurrence-tag action across every page of the current search, scene filters, performer scope, and occurrence conditions, honoring the review's Include subtags setting. Preview lists exact occurrence/scene counts, additions, removals, and conflicts before writing. Conflicts are tags the chosen action would remove: skip them by default or explicitly replace them. Configure opposite answers as removals in the action; the extension does not infer opposites. To include already answered appearances, remove filters that exclude them.

Batch targets and action trees are frozen before writes, with up to five occurrences processed concurrently. Cancel stops scheduling and lets in-flight writes settle. Results distinguish changed, unchanged, skipped, failed, and remaining occurrences. Continue processes remaining items; retry processes failures whose previous outcome can be verified. Affected tags changed since preview are skipped. Inspect failures with unknown write outcomes before creating a new preview. **Undo batch** reverses recorded changes while preserving unrelated edits and reports conflicts. Keep the page open during execution: results and undo remain in memory within the workspace, including through rule editing, and a new batch explicitly discards previous results. No future-import defaults or background jobs are created.

Tag-group reviews retain their Grid/List selection and progress workflow. Review definitions use Cove's account-scoped saved-filter API with browser recovery support. See the [user guide](docs/video-data-quality.md), [interaction contract](docs/data-quality-review-interaction.md), and [storage contract](docs/storage-and-verification.md).

Registry publication remains deferred. Visual-similarity search is not available through the public extension API. No new backend endpoint or database migration is required by this workflow.
