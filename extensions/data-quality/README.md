# Data Quality

Data Quality adds a dedicated Cove page for saved video, performer occurrence, and tag reviews. Enable it in **Settings → My → Interface → Navigation**.

Video and occurrence reviews put the player, active item, current tags, and configured actions beside an independently scrollable queue. Occurrence actions affect only the active performer in that video. Matching partners are reviewed together; switching partners preserves playback and clip boundaries. Video actions affect the video itself. Existing multi-tag actions, explicit absence tags, and legacy occurrence tag-choice reviews remain supported.

The URL owns the complete effective query: search, scene filters, performer scope and occurrence conditions, sorting, page size, page, and traversal direction. Bare review links load saved defaults and serialize them. Query-bearing links remain independent of subsequent default changes, including explicit empty filters. **Reset to review defaults** replaces the current query; **Save as review defaults** opens the workspace rule editor with the current criteria; **Save review** persists the draft. Opening another review starts with its defaults. New reviews start from the end; existing direction settings and explicit URL pages are honored.

Actions apply and advance by default. Shift-click or Shift plus the numbered shortcut applies and stays; each writing action also has **Apply & stay**. **Edit tags** uses Cove's shared tag selector for arbitrary additions and removals. **Save** stays, **Save & next** advances, and **Cancel** discards the local draft. Shortcuts are suspended while typing, editing tags, or using dialogs and player controls.

**Skip** only moves the cursor. Eligibility comes from current filters, without reviewed/inconclusive states or persistent position. Loaded pages stay stable during review and membership is reconciled at page boundaries. Skipped and still-matching items are available again when their page is revisited. Legacy stored progress is left untouched and ignored for video and occurrence reviews.

**Undo latest tag operation** reverses one successful tag operation, including multi-tag actions and ad hoc saves, and returns to its item and page cursor. It stays available after automatic advancement and is kept in memory for the open workspace. Undo re-reads affected tags, preserves unrelated edits, and stops on detectable conflicts. Tag operations are not atomic across requests: failed or partial saves retain the item and draft, refresh actual tags, and provide recovery feedback. Concurrent edits between the final read and write cannot be detected atomically by the existing APIs.

**Apply to all matching occurrences** runs a configured occurrence-tag action across every page of the current search, scene filters, performer scope, and occurrence conditions. Preview lists exact occurrence/scene counts, additions, removals, and conflicts before writing. Conflicts are tags the chosen action would remove: skip them by default or explicitly replace them. Configure opposite answers as removals in the action; the extension does not infer opposites. To include already answered appearances, remove filters that exclude them.

Batch targets and action trees are frozen before writes, with up to five occurrences processed concurrently. Cancel stops scheduling and lets in-flight writes settle. Results distinguish changed, unchanged, skipped, failed, and remaining occurrences. Continue processes remaining items; retry processes failures whose previous outcome can be verified. Affected tags changed since preview are skipped. Inspect failures with unknown write outcomes before creating a new preview. **Undo batch** reverses recorded changes while preserving unrelated edits and reports conflicts. Keep the page open during execution: results and undo remain in memory within the workspace, including through rule editing, and a new batch explicitly discards previous results. No future-import defaults or background jobs are created.

Tag-group reviews retain their Grid/List selection and progress workflow. Review definitions use Cove's account-scoped saved-filter API with browser recovery support. See the [user guide](docs/video-data-quality.md), [interaction contract](docs/data-quality-review-interaction.md), and [storage contract](docs/storage-and-verification.md).

Registry publication remains deferred. Visual-similarity search is not available through the public extension API. No new backend endpoint or database migration is required by this workflow.
