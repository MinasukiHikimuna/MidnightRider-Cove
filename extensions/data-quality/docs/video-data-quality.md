# Data Quality extension

Install and enable the Data Quality extension, then place its top-level page through **Settings → My → Interface → Navigation**. The extension owns this route and has no link to the generic Videos list.

Choose a saved review to open its queue. Each review targets Videos, Tags, or Performer occurrence tags; existing records without an entity type remain video reviews. The type is selected when a review is created and is immutable after save or duplication. **Manage reviews** supports naming, describing, duplicating, deleting, and importing reviews. Video and tag reviews support ordered actions with duplication, reordering, and validated shortcuts. Edit review opens the current review directly. Save and cancel restore focus and queue position. Configuration is saved per account when saved-filter permissions are available; the page identifies browser-only and read-only variants.

For a performer occurrence review, configure the reusable scene search and filters under Queue and buttons under Actions. For example, a hairstyle rule can have Hair down and Pigtails actions that add the corresponding occurrence tags. Actions support adding tags, removing tags, removing a tag tree, and skipping with an empty step list. Optional occurrence conditions can require or exclude exact tags on an appearance, but no performer selection, occurrence condition, or tag-choice list is required to save a review.

While reviewing, use **Filter performers** to select one or more names from the native performer dropdown. An empty selection means all performers. This is a temporary session filter: it narrows both scenes and eligible occurrences without changing the saved rule. Clearing it returns to all performers; reopening the review starts without a performer restriction. Saved performer targeting from the earlier development version no longer limits the workspace. The performer strip identifies the active target, and an action changes only that person's occurrence in the current scene. Other performers, unrelated occurrence tags, scene tags, and profile tags are preserved. Buttons and shortcuts 1–9 apply actions and advance; an empty action skips without completing the occurrence. Video-level present/absent custom-field assessments are not offered for occurrence actions.

**Cannot determine & next** records an inconclusive outcome without modifying tags; **Skip performer** leaves the occurrence unresolved. Saving tag changes requires tag write permission. The player preserves playback between scene partners and respects clip boundaries. After the last pending performer, navigation continues to the next scene, re-reading the current page before advancing to avoid skipping scenes after filter membership shrinks. Existing reviews with a Tag choices list remain usable through **Save & next performer** when no actions are configured; adding actions switches the workspace to those action buttons.

Occurrence progress belongs to the review and performer–scene pair. Temporary performer selection, sorting, and page-size changes retain completed answers; changing the action effects or legacy tag choices starts new answer progress. Review cards count matching scenes before temporary performer narrowing, and the workspace reports unresolved and total occurrences on the loaded page alongside the filtered matching scene count. It does not load the whole library to calculate a global occurrence total. Scene-page controls let you revisit earlier answers or skipped performers. Tag writes use individual public API requests and can partially succeed; failure keeps the current performer active for retry, with no rollback promise.

New tag reviews start with ungrouped tags sorted by name from the beginning. Grid uses Cove's native tag tiles, while List shows the tag name, current group, description, and video count. Enter opens the focused tag detail in a new tab. A tag action has one effect: assign one existing tag group, set the tag to Ungrouped, or Skip. It targets the explicit selection when present and otherwise the focused tag, then refreshes the queue and advances using the same rules as video reviews.

The queue offers Grid and Wall modes with the same responsive card presentation and adjustable card width. Grid uses cover images. Wall plays muted generated previews only near and within the viewport, falls back to cover images when previews are unavailable, and does not record engagement. Cards omit video descriptions and empty annotation sections; the linked video title opens details directly in a new tab, as does the details link in the large preview. The large preview reuses Cove's public `VideoPlayer` component.

Focus and selection are separate. Arrow keys move the single focused video. Space toggles its selection, `A` toggles the videos shown on the page, Enter opens the preview, and keys 1–9 run the matching action. An action targets the explicit selection when one exists and otherwise targets the focused video. The target is stated beside the action controls. Review shortcuts stop in editors and dialogs; player focus retains playback controls.

Actions use Cove's authenticated extension API and existing video write permissions. Add, Remove, and Remove tree retain the bulk execution path for existing reviews. Mark present, Mark absent, and Clear absence store exact tag assessments in the shared, filterable `confirmed_absent_tags` video custom field. Mark present adds the regular tag and clears its absence; Mark absent removes the regular tag and records its absence; Clear absence removes only the stored absence. Assessment actions resolve every descendant-removal step before writing, then read and update each target sequentially with one complete tag/custom-field payload at most. They stop after the first failed target and report both completed videos and the affected video. After success or failure, the queue refreshes, selection is limited to targets that still match, and focus advances or stays according to the interaction contract. The UI never promises rollback, automatic retry, or undo.

The queue uses Cove's native entity toolbar for search, sorting, direction, page size, filter editing, active-filter counts, and applied-filter chips. Those controls adjust the current session directly. **Reset to review defaults** restores the complete saved queue, including search, sort, page size, and filters; **Save queue to review** makes the current adjustment durable. Saved and imported video queues can exclude a reviewed tag with a `confirmed_absent_tags` custom-field criterion of type Tag and modifier Excludes. Video reviews also configure opt-in native card annotations and parent-tag bins. Card width is an in-session view control stored with progress rather than a review setting. Actions can be duplicated and reordered; video action steps can also be reordered; action shortcuts are unique digits 1–9 or None. Navigation keys cannot be action shortcuts. Progress resumes the saved page and entity or the nearest available position, with empty selection. See [storage-and-verification.md](storage-and-verification.md) for migration, permissions, failures, and changing-result behavior. Registry publication, atomic actions, contradiction discovery across the library, and undo remain deferred. Visual-similarity video queue evaluation also remains unavailable until Cove exposes it through the public extension API.
