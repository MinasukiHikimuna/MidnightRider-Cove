# Data Quality extension

Install and enable the Data Quality extension, then place its top-level page through **Settings → My → Interface → Navigation**. The extension owns this route and has no link to the generic Videos list.

Choose a saved review to open its queue. Existing browser reviews and account import bundles are adopted without changing their IDs. **Manage reviews** supports naming, describing, duplicating, deleting, and importing reviews, plus ordered tag actions with duplication, reordering, and validated shortcuts. Edit review opens the current review directly. Save and cancel restore focus and queue position. Configuration is saved per account when saved-filter permissions are available; the page identifies browser-only and read-only variants.

The queue offers Grid and Wall modes with the same responsive card presentation and adjustable card width. Grid uses cover images. Wall plays muted generated previews only near and within the viewport, falls back to cover images when previews are unavailable, and does not record engagement. Each card opens video details directly in a new tab, as does the details link in the large preview. The large preview reuses Cove's public `VideoPlayer` component.

Focus and selection are separate. Arrow keys move the single focused video. Space toggles its selection, `A` toggles the videos shown on the page, Enter opens the preview, and keys 1–9 run the matching action. An action targets the explicit selection when one exists and otherwise targets the focused video. The target is stated beside the action controls. Review shortcuts stop in editors and dialogs; player focus retains playback controls.

Actions use Cove's authenticated extension API and existing video write permissions. Add, Remove, and Remove tree retain the bulk execution path for existing reviews. Mark present, Mark absent, and Clear absence store exact tag assessments in the shared, filterable `confirmed_absent_tags` video custom field. Mark present adds the regular tag and clears its absence; Mark absent removes the regular tag and records its absence; Clear absence removes only the stored absence. Assessment actions resolve every descendant-removal step before writing, then read and update each target sequentially with one complete tag/custom-field payload at most. They stop after the first failed target and report both completed videos and the affected video. After success or failure, the queue refreshes, selection is limited to targets that still match, and focus advances or stays according to the interaction contract. The UI never promises rollback, automatic retry, or undo.

**Adjust queue** provides native video filter editing, search, sort, and page size for the current session. Reset returns to saved filters; Save queue to review explicitly makes an adjustment durable. Saved and imported review queues can exclude a reviewed tag with a `confirmed_absent_tags` custom-field criterion of type Tag and modifier Excludes. Edit review also configures opt-in annotations, descendant-tag annotation parents, parent-tag bins, preferred view, and card width. Actions can be duplicated; actions and steps can be reordered; action shortcuts are unique digits 1–9 or None. Navigation keys cannot be action shortcuts. Progress resumes the saved page and video or the nearest available position, with empty selection. See [storage-and-verification.md](storage-and-verification.md) for migration, permissions, failures, and changing-result behavior. Registry publication, atomic actions, contradiction discovery across the library, and undo remain deferred. Visual-similarity queue evaluation also remains unavailable until Cove exposes it through the public extension API.
