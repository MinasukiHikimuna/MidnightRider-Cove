# Tag of the Day

Tag of the Day adds a home dashboard widget that features one of your tags each day. It picks a random tag that is on at least the configured number of videos and shows the tag's media, its name, tag group, aliases, and description, how many videos, tagged moments, and performers it has, and a row of tagged moments from its videos.

The tag's media is drawn through Cove's `entity.media` boundary, the same one Cove's tag cards use, so it follows Cove's image-fit setting. When an extension such as Animated Tag Previews supplies an animated preview for the tag, the preview plays in the widget too. The media frame has the shape the tag's card has in Cove's Tags grid. That is 16:9 for a tag image or no image. For an animated preview, it is the preview's own shape (4:3 by default, or square or 16:9 when Animated Tag Previews is set to that) while Animated Tag Previews' setting to match the Tags card shape to the preview is on, as it is by default, and 16:9 while it is off. The frame is never cropped to fit; in a narrow column it narrows instead. On Cove versions whose extension runtime does not publish `EntityMedia`, the widget shows the static tag image.

Tagged moments are the tag's segments, sampled from the 100 most recently updated ones, which is what Cove's tag segment list returns, and spread across as many different videos as possible. Each shows the segment's cover image, the time it starts, and its length, and it plays the tagged stretch muted while it is hovered or focused, like Cove's segment cards. Choosing one opens the video at that time. The **Tagged moments** setting decides what fills the row. **Prefer tagged moments** (the default) shows moments first and tagged videos when the tag has too few. **No preference** mixes moments and tagged videos at random. **Only tags with tagged moments** features only tags that have segments and shows only their moments. Cove's tag search cannot filter by segment count, so in that mode the widget walks the day's random tag order a page at a time, up to 1,200 tags, until it finds one. Choosing the tag's media or **Open Tag** opens the tag page, and each count opens the tag page on its tab. The shuffle button picks another random tag and other moments. The selection is stable for the day: reloading the page keeps the day's pick, or the last shuffle, which the browser remembers for that widget until local midnight, when a new day's pick replaces it.

The widget reads through Cove's authorization-filtered tag and video searches and the tag's segment list, and requires tag and video read access. Segment covers also need segment read access, and moment previews and stills need stream access; without them, a moment shows no picture or does not play. The widget adds no database state or endpoints. Its settings are the minimum number of videos a featured tag must be on (1–1000, default 3), the number of moments shown (0–8, default 4), and where those come from (No preference, Prefer tagged moments, or Only tags with tagged moments). Previews do not play when the system asks for reduced motion.

Build a development ZIP from the repository root with `package-midnight-rider-extension --repository . --extension com.midnightrider.tag-of-the-day --configuration Debug` and install the URL it prints through Cove's extension installer.
